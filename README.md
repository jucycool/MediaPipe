# ICT Robotics & Mechanical Engineering - MediaPipe Lab

MediaPipe와 OpenCV를 활용한 컴퓨터 비전 실습 프로젝트입니다.

## 📌 주요 기능 (Lab Tasks)
1. **Hand Detector (`hand_detector.py`)**: 로컬 동영상(`Hand.mp4`) 기반 손가락 랜드마크 검출
2. **Hand Detector YouTube Stream (`hand_detector_youtube.py`)**: 유튜브 온라인 스트림 기반 손가락 랜드마크 검출
3. **Face Detector (`face_detector.py`)**: 로컬 동영상(`face.mp4`) 기반 얼굴 메시(Mesh) 검출
4. **Selfie Segmentation (`selfie_segmentation.py`)**: 실시간 배경 분리 및 블러(Blur) 처리

## 🛠️ 실행 환경 및 필수 패키지
- Python 3.10+
- `pip install -r requirements.txt`
